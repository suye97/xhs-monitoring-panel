# 小红书舆情监控

基于 Electron、TypeScript 和 React 的独立桌面应用。通过 OpenCLI 2.0.3 的只读命令采集小红书笔记与评论，展示情绪、互动量、最近八次趋势和完整历史快照。唯一数据源为 **OPENCLI笔记与评论**。

## 功能

- 按最新排序搜索最多 6 篇笔记，逐篇补全正文和互动指标。
- 每篇请求最多 10 条一级评论，最多保留 20 条文本评论及回复（合计）。
- 展示笔记和评论的负面占比、已知互动量、评论扫描覆盖及失败原因。
- 支持取消采集；应用可见且启用自动刷新后，每 30 分钟重新采集当前关键词。
- 每次成功采集保存完整快照，最多 80 条。点击「查看详情」可查看当时的笔记正文、互动数据、评论及回复，不会重新采集；重启应用后仍可查看。
- 取消或失败的采集不新增历史。旧浏览器版本只保存统计摘要，不能还原完整详情，本版本不会自动导入这些摘要。

## 准备运行环境

1. 安装 Node.js 20.18.1 或更新版本，并确保 `node` 在系统 `PATH` 中。也可用 `XHS_MONITOR_NODE_EXECUTABLE` 指定 Node 可执行文件。
2. 在 Chrome 安装并启用 OpenCLI Browser Bridge，在同一浏览器登录小红书并保持浏览器打开。真实采集需要 `extensionConnected`，可用 OpenCLI `doctor` 命令检查。
3. 应用依赖中已固定 OpenCLI 2.0.3。需要单独安装时，可用 `XHS_MONITOR_OPENCLI_ENTRY` 指定其 JavaScript 入口绝对路径。打包后入口必须位于可执行文件可读取的真实路径，不能只存在于应用归档内。

请仅在有权使用相关数据和浏览器会话的环境中采集。平台登录状态、验证码、访问频率或反自动化策略可能影响结果；部分笔记失败时，已成功样本和跳过原因仍会保留。

## 开发、检查和打包

```powershell
npm ci
npm run dev
```

```powershell
npm run typecheck
npm test
npm run build
npm run dist
```

- `dev`：启动带开发热更新的 Electron 应用。
- `typecheck`：严格 TypeScript 检查。
- `test`：运行采集、历史存储、IPC 和 React 组件测试；测试使用替身，不访问真实小红书。
- `build`：生成 `out/` 下的主进程、preload 和渲染进程产物。
- `dist`：通过 electron-builder 生成 Windows NSIS 安装包。

## 数据与安全

历史文件为 Electron `userData` 目录下的 `capture-history.json`，包含所采集的笔记和评论文本。写入采用临时文件加重命名，读取时校验结构；损坏或不符合结构的数据不会被当作有效历史展示。请按本机敏感数据要求保护该目录。

渲染进程不开放 Node.js。主进程通过固定 IPC 通道提供采集、取消、历史查询和原帖打开功能；外部链接仅允许已校验的小红书 HTTPS 笔记地址，并由系统浏览器处理。窗口启用上下文隔离和沙箱，拒绝新窗口及页面导航。

## 统计口径

笔记负面占比为负面笔记数除以存在标题或文本的笔记数；混合和中性计入分母，无文本样本单独显示。评论负面占比只计算本次实际采到的文本评论和回复。已知互动量为已知的赞、评、藏和分享总和，缺失指标不按零补齐。中文词规则可能受反讽和语境影响，结果仅供观察样本趋势。
